About

Where's My Toilet? is a short, silly 3D browser game. You're in a crowded, maze-like shopping mall and you really, really need to go. Every round the mall is laid out differently.

How it's made

The game runs entirely in your browser — nothing to install and no server. It's built with Babylon.js, TypeScript and Vite, and is hosted on GitHub Pages. Every sound is synthesised live in your browser with the Web Audio API, so there are no audio files.

All shop names are made up. Any resemblance to real shops is a happy accident.

Source code

The code lives at github.com/theanam/wheresmytoilet.
